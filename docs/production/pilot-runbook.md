## 📱 PHASE 2: WHATSAPP PILOT LINE ONBOARDING

### 1. Webhook Endpoint Setup
- **Webhook URL:** `https://app.willshop.os/api/webhooks/whatsapp/meta`
- **Verify Token:** Set `META_WEBHOOK_VERIFY_TOKEN` in Vercel environment settings.
- **Subscribed Events:** `messages`, `message_deliveries`, `message_reads`.

### 2. Signature Validation Test
Send a sample payload with HMAC-SHA256 signature to verify authentication:
```bash
curl -X POST https://app.willshop.os/api/webhooks/whatsapp/meta \
  -H "Content-Type: application/json" \
  -H "x-hub-signature-256: sha256=VALID_HASH_HERE" \
  -d '{"object":"whatsapp_business_account","entry":[{"changes":[{"value":{"messages":[{"from":"22670000001","id":"wamid.test","text":{"body":"Bonjour WillShop"}}]}}]}]}'
```
Expected response: HTTP `200 OK` with `{ "status": "RECEIVED" }`.

### 3. Human Handoff Test
1. Customer writes: `"Je veux parler à un agent humain"`.
2. AI Sales Agent flags conversation status: `HUMAN_HANDOFF_REQUIRED`.
3. Notification dispatched to Commercial Team Inbox in CRM.
4. AI auto-reply pauses until Commercial takes over or resolves handoff.

## 🚨 ESCALATION & EMERGENCY EMERGENCY PROCEDURES

If an anomaly occurs (e.g. duplicate messages, incorrect price quotes, unexpected stock depletion):

1. **Activate Kill Switch Immediately:**
   Navigate to `/automation` -> Click **Kill Switch** -> Select **Stop AI Sales Agent** or **Stop Outbound Automation**.
2. **Fallback to Manual Mode:**
   Sales team takes over WhatsApp lines directly via Meta Business Suite or WhatsApp Web.
3. **Inspect Logs:**
   Filter logs by `correlation_id` in Vercel or Supabase Dashboard.
